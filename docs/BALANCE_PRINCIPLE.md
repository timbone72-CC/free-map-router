# Balance Principle

The guardrail system must reduce the chance of damaging a working app without
making ordinary development unnecessarily slow.

- Low-risk changes stay lightweight.
- Normal features receive focused protection.
- High-risk data and deployment changes receive stronger controls.
- Automated checks carry repeatable verification work.
- The same unchanged scope is not sent through repeated approval loops.
- A failed branch may be repaired or abandoned without blocking unrelated work.
