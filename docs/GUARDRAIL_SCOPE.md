# Guardrail Scope

These guardrails protect the entire Free Map Router application and future
changes. They are not a numbering-specific patch.

They cover:

- product and data contracts;
- page ownership and responsiveness;
- address selection and editing;
- route building and optimization;
- Google Maps and Garmin exports;
- Google Drive and backup behavior;
- runtime script ownership;
- risk-matched testing, review, deployment, and rollback.

The system must prevent unsafe live experiments while keeping low-risk and
normal development practical.
